JOB REGISTER - APK बनाने का तरीका (बिना Android Studio के)

1. github.com पर मुफ्त खाता बनाइए और एक नई Repository बनाइए (नाम: job-register).
2. इस ZIP की सारी फाइलें (www फोल्डर, .github फोल्डर, package.json, capacitor.config.json) Repository में Upload कीजिए.
   ध्यान रहे .github फोल्डर भी जाए.
3. Repository में ऊपर "Actions" टैब खोलिए. "Build APK" अपने-आप चलना शुरू हो जाएगा (5-10 मिनट).
   न चले तो "Build APK" चुनकर "Run workflow" दबाइए.
4. हरा निशान आने पर उस रन को खोलिए. नीचे "Artifacts" में "JobRegister-APK" है. उसे डाउनलोड कीजिए.
5. ZIP खोलने पर app-debug.apk मिलेगा. उसे फोन में डालिए और खोलिए.
   "Install unknown apps" की अनुमति माँगे तो दे दीजिए.

सिस्टम की जरूरत: कुछ नहीं, सब GitHub के सर्वर पर बनता है.
